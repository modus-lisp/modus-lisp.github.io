# Modus REPL

The Modus Common Lisp system, compiled to MVM bytecode and run by a JavaScript
interpreter in a Web Worker.  Static; no server code.

Generated by `web/deploy-pages.sh`-style copy from the `web-interp` branch of
the modus repo (source: web/*.js, web/index.html, web/coi-serviceworker.js).
Do not edit here.  `coi-serviceworker.js` supplies the COOP/COEP cross-origin
isolation that SharedArrayBuffer needs and that GitHub Pages cannot set via
headers; it is scoped to this directory only.
