kiln  /  21 commits, all of them its first

A desktop you can install

On Tuesday a repository appeared containing one idea: take the forty-two checkouts that make up this workspace and fire them into a single image that boots a desktop. By Friday it could do that on Docker, on podman, on Apple’s container runtime, out of a plain folder with no container at all, and on Windows.

The build bootstraps itself in Lisp, and the way it does that is the most modus-lisp thing in the week. Five repositories arrive as tarballs — cairn and its closure, which between them depend on nothing third-party — and then cairn, the org’s own from-scratch git, clones the other thirty-three out of GitHub over seal’s TLS. There is no git binary in the image. repos.lock pins every commit and kiln lock refreshes it through cairn’s own ref discovery, which needs no GitHub API and no token.

The rest of the week was the difference between a demo and a thing you hand somebody. The browser became the default surface and VNC the opt-in. A published port lands on loopback unless you ask otherwise. The box configures over ssh, menuconfig style. The agent runs inside fences, and the mount list is the fence. And on Thursday a second new repository, glass-sdl, gave the desktop a native window — verified 13/13 on real Windows hardware with a real video driver, then saved as a standalone executable.

Four rungs went up in a day: a bare-metal Raspberry Pi 3B image on the CL/mvm stack, then that image fetching a .tar.gz over real HTTP, then installing, loading and calling the library inside it, and then the whole thing on real Pi Zero 2 W silicon. Getting there needed the mini UART rather than the PL011 for chain-loaded images, a loader protocol that carries the load address on the wire, and VBAR_EL2 set as well as VBAR_EL1, because the image runs at EL2.

Two bugs inside the garbage collector

Turning on allocation bitmaps for bare-metal aarch64 — #160 — found a collector that had never actually forwarded anything.

(mem-ref A :u64) does not return the machine word at A. The loaded word is left untagged, so every later Lisp operation reads it as a tagged value: the integer handed back is word/2.

gc.lisp — 6c1b027, proven against physical memory with gdb

The docstring blamed i386 and claimed x64 and aarch64 used native trampolines instead. That was false for aarch64, whose trampoline is a register-saving shim that calls this same Lisp collector — so every bare-metal Pi image was running it. Its sibling bug is almost funnier: all four bitmap helpers wrote their mask with (ash 1 bit) for a variable bit, and a variable shift count routes through the runtime BIGNUM-ASH, which conses. Each of them runs inside %gc-collect, where the alloc pointer is already at the limit, so a single cons re-trips the GC check and re-enters the collector. They had never been exercised, because the targets with bitmaps on used a different path.

A fork nobody had noticed

#266 cut 871 lines by making the bare-metal RPi build a thin tail over the shared CLI assembly instead of a private fork of it. Twenty-seven of its thirty-eight defvars were verbatim copies; among the duplicated code was a complete x64 JIT block baked into an aarch64 image, dead only because its *jit-on* was NIL. The commit names the cost plainly: this is the shape of the console and USB-DMA bugs from the same week — a fix lands in one assembly and not the other.

seal  cl-nostr  cairn  /  8 commits

One HTTP client, at last

Four hand-rolled HTTP clients had grown in this workspace, because there was nowhere for one to live: cairn’s 108 lines, just enough for git’s smart transport; weft’s 527, the mature one, reachable only by depending on a browser engine; skep’s; and cl-nostr, which had given up and reached for dexador — which is cl+ssl, which is OpenSSL through an FFI, in a workspace whose whole claim is that there isn’t one.

So HTTP/1.1 moved into seal, on seal’s own TLS: URLs with bracketed IPv6 authorities, chunked and Content-Length bodies, read-to-close, plain http:// over a raw socket as well as https://, and redirect following where 303 and a 301/302 on a POST degrade to GET without the body, which is what clients actually do. An RFC 6455 WebSocket client followed it out of modus. cairn stopped being a fourth client; cl-nostr moved its relays, NIP-05 lookups and Blossom uploads across and is now FFI-free.

One thing that fell out of the move is worth its own paragraph. cl-nostr found that secp256k1-fast keeps mutable state across a scalar multiplication, so two threads signing at once do not merely contend — they corrupt each other. Of eighty signatures taken from four threads, seventy-seven signalled and the three that returned were invalid. Silently invalid is the dangerous half: the event looks complete, and the relay that rejects it reports a bad signature for a key you know is good. A pool fans out and an uploader fans out, so the lock went underneath everybody rather than into a note asking each caller to remember.

glass  webrtc-data  /  27 commits

A link a person has to spend

Handing somebody a desktop over a DM means handing them a code, and a code that can be used twice is not much of a code. So an enrolment became a record: revoking marks it, the box says when it runs out, and it tells the client so before the client is surprised. A login code is traded exactly once, and cancelled when it turns out not to be needed.

Then the interesting failure. Single use gives a real property — a successful redemption means nobody else got there first — but only if a code cannot be spent without a person. These links arrive in a DM, and preview bots fetch them; some render the page in a headless browser. One of those would connect, bind the code to its own throwaway key, and the human’s tap would be refused as a leak: a false alarm that locks the owner out, caused by the defence.

So the gate sits on redemption, not on connecting. A returning terminal has an enrolment and spends nothing, so it opens straight away; only a load actually carrying a live code waits for a finger.

glass-webrtc — 78b4b63

Around that: glass grew a single control socket that answers even the form it cannot read, two seats onto one real desktop with a gate that proves it, seats bound to loopback unless somebody asks otherwise, and a terminal window whose shell is a Lisp listener. And the box now writes down which route a session took and how it ended, so “it didn’t connect” has an answer.

mill  stave  chord  /  12 commits

The half that listens

mill learned to read a .onnx in Lisp and convert it once, to carry a model’s config alongside its graph, to handle subgraphs, and to pack the B operand of a matmul and pool its workers — with the gates that keep all of it honest. On top of that stave got its second half: beam search, a lexicon, streaming, and a word error rate to be judged by. chord can now fetch a voice from Lisp and convert it.

chord also spent three commits on a licence, which is not the kind of thing a weekly usually reports. Piper’s model card for the Lessac voice says MIT — but that covers Piper’s repository, not the speech it was trained on, and the Blizzard 2013 licence it links to grants research use only and forbids redistribution. Weights trained on that data are a derived work of it. So the voice cannot ship; the README says how to fetch and convert one yourself, and why cmudict and the rules learned from it do ship, being BSD. A dataset licence and a model licence are routinely different, and the dataset is the one that binds.

stencil  /  8 commits

Graded against a browser, not against itself

stencil’s self-test asked stencil whether stencil agreed with stencil. Twenty-three checks, all green, and underneath them <pattern> rendered nothing at all: the paint server was not implemented, url(#id) resolved to no paint, and the shape was silently dropped. Nothing in a self-referential suite knows what the pixels were supposed to be. It surfaced when a wallpaper named for its patterns came out with no patterns in it.

The grader is now Chromium. Each test renders as a top-level file:// document at a size computed from width, height and viewBox; stencil renders the same file into the same box; both composite onto the same white and the pixels are compared. In the week that followed, masks, clips, patterns, rounded rects, every colour name, <use> cycle detection, <image> through a hook and .svgz all landed — along with a note recording where the oracle itself is wrong.

everywhere  /  one line at a time

Nobody lives in /home/claude

The quiet theme of the week, and the reason for its title. Half a dozen repositories had hard-coded a path that happened to be right on one machine:

  • weft takes the WPT checkout from $WPT_ROOT.
  • loom takes Playwright, Quicklisp and WPT from $HOME.
  • warp and spool resolve the workspace from the script that is running, and glass from the file asking for it.
  • glass derives every load-asd from *load-truename*, and finds Quicklisp rather than assuming a home it owns.
  • webrtc-data finds esbuild under $HOME, and its deploy scripts say what to do instead of how to do it.

None of these is interesting on its own. Together they are the difference between a workspace that runs where it was written and one that runs in a container, in a folder, on Windows, or on a Pi — which is exactly what the rest of the week was about.
