the workspace  /  10 first commits

Ten repositories in seven days

Sunday: natrium. Tuesday: conch. Wednesday: cairn. Thursday: cabinet, cram, dist, operandi, and a framebuffer called scry that was renamed glass before the day was out. Friday: cl-frpc and webrtc-data.

What makes it a week rather than a list is the order. natrium is a hashing floor, then a CSPRNG, then ChaCha20-Poly1305, then X25519, then Ed25519 — the NaCl set, completed on Sunday and made constant-time on Monday. conch appears on Tuesday and takes its crypto from natrium; by Thursday it has publickey auth, exec, scp, SFTP and a server. seal, which already existed, deleted its own symmetric and curve code and delegated to natrium the same week. cairn borrows SHA-1 from seal and gets git-over-SSH from conch. cabinet is a filesystem built on pagetree, and cairn immediately learns to keep a repository inside one.

Route cairn’s git store through a small backend protocol, so the same cairn can keep a repository on the host filesystem or inside a cabinet, which lives in a single pagetree file. This is what lets cairn run where there is no host filesystem at all.

That last clause is the whole project in one line. Every library here is written as though the operating system underneath it might not be there — because the point is that eventually it will not be.

glass  /  35 commits, most of them on one day

A framebuffer on Thursday, a desktop on Friday

It starts as “a framebuffer + VNC/RFB server in pure Common Lisp”, gains dirty-region tracking, Hextile (about 88× smaller than raw) and ZRLE over a persistent cram stream, and is renamed. Then Friday happens.

A McCLIM backend, modelled on the X framebuffer one: CLIM applications render into a glass framebuffer and are served over RFB, with keyboard and pointer coming back from the VNC client — no X, no FFI. Resize in both directions, and stock McCLIM apps running unmodified. A compositor for menus, dialogs and pop-ups. Real keyboard focus, so the Listener REPL evaluates over VNC. A mini OPEN LOOK window manager. Then the window manager stopped using McCLIM for its own chrome, because glass now owns text through scribe.

And then a terminal emulator, which arrives essentially complete: a real pty, ANSI, a scribe glyph grid, UTF-8 with wide characters and fallback fonts, colour emoji through scribe’s COLR support and its bundled Twemoji, a hardened VT with 256 colours, the alternate screen and cursor operations so that htop and vim work, mouse reporting with a real controlling tty, tabs, and Sixel graphics for inline bitmaps. The root menu that opens on a right-click offers a browser window, an image viewer, a terminal, McCLIM’s calculator, and — from Genera’s lineage — the Clouseau object inspector and a graphical debugger.

cairn  /  27 commits over two days

git, read then written then served

Wednesday: read a repository — SHA-1, DEFLATE, loose objects, refs, log — then packfiles with delta-compressed objects, then clone over smart HTTP, then checkout, then the write side, at which point real git accepts the commits it produces. Then status and diff matching git’s three-way output, push over SSH, fetch and fast-forward pull, a real three-way merge with a pluggable conflict resolver, recursive merge over multiple merge bases for criss-cross histories, delta compression in written packs within a few percent of git’s own, push over smart HTTP, and SHA-256 repositories, git-validated.

Thursday was the part that matters for a machine with no Unix underneath it: the storage backend seam described above, a worktree backend so a full working tree lives in a cabinet, a direct pagetree backend where a commit and a push are one transaction, and cairn’s own git server speaking upload-pack and receive-pack over SSH. Two performance fixes on the way: streaming index-pack for bounded memory, which fixed cloning large repositories out of memory, and a parallel resolve that made index-pack about eight times faster. And a small one with a large principle behind it — the nproc shell-out was dropped, because nothing in the core chain may spawn a process.

modus  /  43 commits  /  WS4, WS5

A CLI that compiles without SBCL

The two workstreams that would close the self-hosting cycle the following week both took their shape here. The runtime JIT came up in five stages — the x64 translator baked into the evaluator image as dead code, then real forms compiled end to end against an interpreter oracle, then native call relocation for out-of-module calls, then a constant pool with GC-durable literal patching, then wiring into production evaluation behind a flag.

The other produced a modus binary with the whole x64 build toolchain baked into it, so it compiles Lisp to a native Linux ELF entirely in-image — SBCL needed only to seed the CLI once. What stood between that and self-hosting was reading: the compiler could not yet read its own sources in-image. A lenient missing-package recovery for modus.* qualifiers took the skipped forms from 204 to zero.

Underneath, byte-packed specialized arrays, a garbage-collector check before every object, array and string allocation — which fixed losing the root of a large bignum — and a build taxonomy written down for the first time, with the shared ANSI gate harness extracted so the x64 and aarch64 pairs stop drifting apart.

weft  loom  /  123 commits

Tables, baselines, and a browser with tabs

weft spent 105 commits in the least glamorous corners of CSS, which is also where the difference between a renderer and a browser lives: table height distributed across rows, a cell that never shrinks below its content, calc(% + px) column widths, flex item margins on both axes and in both directions, min and max clamping on flex, grid and table containers, position: sticky including percentage insets and the right containing block, and a run of line-box work — text painted on the baseline, atomic inlines baseline-aligned, the strut descent kept under a tall one.

loom turned into something you could use: per-tab sessions with distinct browsing contexts, a per-context cookie jar threaded through the render (workers included), a tab bar with a pinned engine-status tab, a thread per connection so one render cannot freeze the service, and each navigation bound to the tab that started it. Bounded waits arrived for web fonts and image prefetch, so a slow asset degrades the page instead of stalling it. And by Friday loom had a glass backend — the browser driven over VNC, with no SDL and no FFI anywhere in the path.

also this week

The rest of it

  • operandi arrived as a Lisp-native ReAct agent loop and grew an interactive REPL with streaming and tool rendering the same day. Its launcher went from about 16 seconds to 60 milliseconds by dumping a core.
  • cram was a DEFLATE compressor on Thursday morning and a full codec by the afternoon, with dynamic Huffman blocks and per-block type selection. cairn dropped chipz and salza2 for it before the week ended.
  • webrtc-data went from an SDP and STUN foundation to a working data channel in a day, each rung verified against aiortc rather than against itself: ICE completed, DTLS connected, then SCTP and DCEP carrying messages.
  • dist began publishing the workspace as a Quicklisp distribution, which is how any of this becomes installable by anyone else.
  • cl-transport gained an inbound side symmetric to its outbound dial, and cl-frpc appeared to reverse-proxy through it — the first answer to “how does a box behind NAT get reached at all”.
