modus  /  #211, #241  /  nine registries

Two packages, one variable

A Lisp keeps a lot of tables: what is a generic function, what is a macro, what is a type name, what is a special variable, which class a condition belongs to, what a setf of this name expands into. Modus keys those tables by name. Over the week it emerged that nine of them were keyed by the name and not the package it lives in — so da::*v* and db::*v* were the same entry.

The generic-function registry is the one worth dwelling on, because it was already package-exact on its primary lookup. The blindness lived entirely in a secondary hash pass that exists to bridge two representations of the same symbol, and that pass compares a hash of the plain name. Probed directly: the hash of ma::zz and the hash of mb::zz are the same number. A generic function defined in one package could be dispatched from another, silently, with no error anywhere.

The rest fell in the same shape — deftype, symbol macros, setf expanders, compiler macros, defstruct, method combinations, the CLOS class and condition registries (which fixed cross-package handler-case), the runtime macro expanders, and special variables, where a global write had to start keying by name rather than by the symbol object. Each one got a battery covering both directions, and the family was declared closed.

modus  /  #242, #245, #248, #251, #252

The build starts checking itself

One of Modus’s standing limitations is that a defvar’s init thunk only runs if this image’s kernel-main calls init-all-globals. That had produced five separate production bugs, each found the hard way. The pattern is mechanical, so this week it became a build check that fails the build and names the variable.

The unit of analysis is the assembled blob one build script hands to the image builder, not a source file — because the last bug was a function that existed and was correct in every file, and that three of ten build scripts simply never called.

build-checks — 09355d2

It immediately found a live one: the shipping AArch64 CLI never called init-all-globals at all, leaving 150 globals unbound. Its siblings arrived over the next three days — a sweep of every first-party file for read errors, which found two unescaped quotes that had made two build scripts unbuildable; a check for let of an unregistered special, which found seventeen live bugs; and a compiler-warning histogram with a ratchet, so the number can only go down.

Reproducibility got the same treatment. The MVM compiler was drawing gensyms from the host’s counter, which made the host’s state an input to the image; it now has its own, with names collision-proof by construction rather than by luck, and the three pins that had been holding the old behaviour in place were dropped.

modus  /  #259, #261  /  three CLIs become one

One lineage, three architectures

The i386 CLI was a third build lineage. It loaded the loader directly and re-derived the entire source set by hand — its own defun scanner, symbol-name scanner, macro-table scanner, opcode emitter, float-slot override and boot sequence, all running parallel to the shared one. The consequence was not stylistic: it baked zero library surface, so the twenty-two-library ladder and alexandria’s test suite could not run on 32 bits at all. Converged onto the shared assembly, it went from 2,145 lines to 384. The aarch64 CLI went the same way the day before — and that convergence fixed four defects by itself, because the fixes had only ever landed in one of the two copies.

With all three architectures finally measurable, i386 got x64’s 16 MB GC arena guard band and twelve of its thirteen SIGSEGVs became exit 0; aarch64 got the same invariant asserted at build time rather than relied on. A zero-init hypothesis for the remaining i386 fault was tested and disproved, and the disproof was recorded rather than quietly dropped.

And the ladder

Underneath all of that, a long list of conformance defects, each one found by a real library refusing to load. CHECK-TYPE was a no-op at runtime. WITH-STANDARD-IO-SYNTAX was silently a PROGN in clean images. READ-SEQUENCE and WRITE-SEQUENCE parsed their keyword arguments positionally. CATCH/THROW and cross-unit RETURN-FROM truncated to a single value. A stale multiple-value count leaked out of an AND- or OR-tailed function as phantom extra values. ASSERT was not a macro, so it evaluated its places. DO dropped a step form that was literally NIL. CHAR-CODE-LIMIT did not exist. :LITTLE-ENDIAN was not in *features*, which is why babel raised a program error.

A package symbol table became an O(1) hash index, which recovered three reader tests above U+00FF and took one gate shard from 139 seconds to 21. And the week closed with alexandria’s own 230 tests all running to completion and passing — the skip list kept, but empty, because an empty list is the honest inventory of what does not terminate.

glass  warp  /  44 commits

A seat is who is watching

A glass port had been two things wearing one name: the session — the applications, their windows, the pixels in them — and the single person watching it, with a screen, a pointer, a keyboard, a focus, an open menu and an arrangement of windows. Nothing forced them apart while there was one viewer, and everything about a second one is the second half.

So a seat is now its own thing, holding what a second watcher must not get a second copy of: its own framebuffer and size, its own wallpaper rasterised at that size (a phone and a desktop want the same picture, not the same pixels), its own pointer, its own focus. A second person can now be on the same windows, arranged their own way. The menu belongs to its window, on whichever screen is watching. My mix is not yours, and my microphone is mine. A seat mints its own npub once and remembers it, and serving is the seat’s decision rather than the session’s.

The same idea arrived in warp from the other end, and the commit that records it is unusually candid about being wrong first.

The boundary was one level too high. Sharing a projection necessarily shares scroll and window size, which makes “independent scroll over one projection” unimplementable. The projection should hold the query; present, layout, diff and encode belong to the consumer.

warp rule 8 — d8a00f5

The forcing argument is that a DOM consumer lays out in a browser with its own viewport, while a token consumer has no extents at all. With that settled, warp grew a third encoding — a browser’s DOM, over its own protocol and nothing else — moved the protocol into a core that loads in an image without glass in it, and reached rule 9: an app is a bundle of facets and the consumer chooses which one it wants.

webrtc-data  warren  /  27 commits

The box answers its own door

The phone client stopped being a demo. The box got an identity of its own and refuses to run without one; admission became the desktop’s answer, with the gateway merely asking for it. The terminal list and then a file browser arrived on the connection the phone already had, rather than each opening their own. A small stable shell lives on nsite and pulls the rest of the client from the box, so the part that must never break is the part that almost never changes. And a pile of real-world corrections: iOS restores a tab without ever firing visibilitychange; the page now says whether the link is still there; a reconnect stays in the corner instead of taking over the screen; a feature nobody has used yet does not get to take the desktop down.

warren, meanwhile, moved the box’s identity and its DM bot out of the gateway and into the desktop, stopped listening on every interface, and fixed the banner that went on saying 0.0.0.0 after the bind had moved to loopback — a small thing, but the kind that costs somebody an hour.

operandi  /  11 commits

An agent you can text

operandi grew a headless mode that runs over Nostr NIP-17 private DMs: it greets the operator on startup if asked, keeps a fixed admission floor so nothing arrives out of order, stays quiet about backlog, and splits a long reply into clean messages instead of truncating it. Underneath, sessions became an append-only entry tree whose state is derived by replay, and the engine stopped fabricating cost numbers, started surfacing provider errors, and now preflights the model before it commits to one.

across the workspace

  • scribe dropped its own DEFLATE and reads WOFF1 through cram, vendored as a submodule the way brotli-pure already was. cram had just learned gzip and crc32 — and fixed stored blocks over 64 KB, which were being silently truncated.
  • On 12 August, ten repositories committed the same one-line change: find sibling repos relative to the script, not to a home directory that happens to exist on one machine. The sweep finishes in № 24.
  • glass stopped calling setsid unconditionally, which does not exist on macOS or the BSDs.
  • spool and warp picked up a README and MIT, to match the rest of the org.
