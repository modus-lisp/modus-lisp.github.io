weft  /  181 commits, from nothing

A URL parser on Sunday, Acid3 on Friday

The first commit is titled “start a self-sovereign web engine” and contains a WHATWG URL parser. The second raises its conformance from 97.2% to 97.7% by handling spaces in an opaque path before the query and fragment. The third is where the week’s method shows up for the first time:

weft — 28 June, four commits in a row 
P0 encoding: kernel + UTF-8 decoder + differential oracle + worker stubs
P0 encoding: 7 decoders built by a parallel agent swarm
P0 encoding complete: 11/11 charsets (CJK via refined swarm)
P0 encoding: full WHATWG decoder set (36 charsets)

A kernel and an oracle first, then workers fanned out against the oracle, then a mop-up pass for whatever the fleet could not close. It is the same shape as the WPT swarm that would drive weft’s forms work three weeks later in № 20, and it explains how 181 commits happen in seven days. It also explains the line counts: most of what landed is vendored conformance corpora — tokenizer vectors, URL test data, character tables — checked in so a gate can run offline.

From encoding the week ran through the HTML tokenizer and tree builder, the CSS cascade, layout, painting, then scripting: the DOM bound to a JavaScript engine, hit-testing, box-tree rendering, viewport scroll and UI event dispatch, canvas gradients with alpha compositing, and <img src=svg>. The last Acid3 cluster closed on Friday — a NodeIterator mutation case and XHTML frame scripts — taking it from 98 to 100. And one commit in the middle deserves a mention for taste alone: the Big5 table was rewritten as a data literal instead of fourteen thousand setf statements.

shuttle  /  80 commits, from nothing

12.4%, then 88%

shuttle started on Tuesday as a skeleton — a value model, a bytecode VM, and the seam through which a host binds its objects. Control flow and a test262 harness followed the same day, which produced the first real number: 12.4% of 47,058 tests. The commits after that read as a ratchet, each one recording where the count stood, and the history rows are kept in the repository so the curve is auditable rather than remembered. It closed the week at 41,404 of 47,058 — 87.99%.

Getting there meant building the standard library rather than the language: property introspection and abstract operations, Symbol, regular expressions, BigInt, and — because test262 does not grade on charm — Intl collators, segmenters and display names. The last commits of the week point back at the DOM: exported host-binding predicates and a microtask drain, which is what weft needed to run scripts on a real event loop.

scribe  gesso  stencil  loom  /  68 commits, four new repos

Everything under the pixels

scribe began on Monday with a scaffold and gamma-correct linear-light compositing — the right order for a rasterizer, since blending in the wrong space is the kind of mistake that is invisible until it is everywhere. It adopted the same swarm method, with an sfnt kernel and ttx as the oracle, and by that evening had the metric, naming and cmap tables green, glyf outlines, an analytic rasterizer, and CFF/Type2 cubic charstrings with flex. By Friday: OpenType shaping with cached lookup indices, hinting including a light Y-only mode that grid-fits vertically while keeping fractional horizontal positions, bounded glyph caches, and a premultiplied RGBA canvas.

Friday added the three pieces that turn a rasterizer into a browser. gesso is 2D vector graphics on top of scribe’s coverage contract — paths, strokes, gradients, an RGBA canvas — and its second commit fixes stroke join squares whose winding was cancelling them out under a non-zero fill. stencil parses SVG and renders it on gesso. loom is a window: an SDL2 shell over weft with DOM input, launched with a four-gigabyte heap and a large control stack, because — as its own commit message puts it — the JS engine recurses deep.

modus  /  66 commits  /  WS3

The flip

While the browser was being built, Modus was changing how it runs Lisp at all. The bytecode evaluator had to reach parity with the tree-walker before it could replace it, and the week is a list of the places parity was missing: catch and throw through the interpreter’s setjmp/longjmp, closures that capture and mutate, secondary values across the runtime-call bridge, higher-order calls with a function object, defstruct, handler-case catching a signalled condition, CLOS initarg validation and compiler macros, defgeneric options, method combinations, and top-level defun persistence — the keystone, because ASDF needs it.

Two pieces of process are worth more than the fixes. An in-image differential gate runs the same form through both evaluators and compares, so parity is measured rather than asserted; and the flip itself was made reversible behind a switch that is byte-clean when off, so the default could move and move back. It moved on Friday: production eval and load became compile-to-bytecode. Compile caching made repeated forms about twenty times faster, which is what made that affordable. The tree-walker survived one more week; № 18 is its obituary.

also this week  /  four more new repositories

Compression, Tor, and Nostr

  • brotli-pure and zstd-pure both appeared on Sunday and both went to full codecs — RFC 7932 decompression and an entropy-coding encoder for the first, Huffman and FSE for the second. Brotli is not optional decoration: it is what WOFF2 web fonts arrive compressed with, which scribe needs and weft needs.
  • cl-tor went from three-hop circuit construction to streams and a SOCKS5 proxy — curl through Tor works — then consensus signature validation with weighted, exit-aware path selection, SENDME flow control, guard persistence, and relay-family and /16 path constraints. A week later it would be hosting an onion service of its own.
  • cl-nostr arrived as a from-scratch Nostr client, and secp256k1-fast made its secret operations constant-time — which both cl-nostr and cl-consensus recorded by rewriting their disclaimers rather than quietly benefiting.
  • cl-consensus grew a parallel peer dialer with correct read-loop ownership, a self-healing follow loop with archival backfill, and a bounded wait on header sync so that a silent peer cannot hang the node.
