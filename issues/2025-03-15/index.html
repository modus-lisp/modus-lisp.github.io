Modus: bare-metal Lisp OS on Movitz

There is no scaffolding commit, no “initial import”, no README landing first. The repository begins with a working operating system:

Boots x86 hardware (or QEMU) into an interactive Common Lisp REPL over serial console. Includes TLS 1.3, SSH server, e1000 networking, and Ed25519/X25519/ChaCha20 crypto — all in Lisp, no underlying OS.

modus — abd9648, the whole commit message

The foundation is Movitz, an x86 Common Lisp environment that runs with no operating system beneath it — a project that had been quiet for many years. Building on it means the hard part — a Lisp that exists before Unix does — is already answered, and the work is everything above: drivers, a network stack, ciphers, a protocol.

That choice is also the reason this issue has a sequel and not a continuation. Movitz is 32-bit and it is somebody else’s foundation, and a project whose whole argument is that you should be able to read every layer eventually has to own the bottom one too. When work resumes in February 2026, it does not resume here.
